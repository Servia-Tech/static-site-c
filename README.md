# Shaheen Shafi Unani Clinic & Hijama Center — website

Static, GitHub-Pages-ready site for the clinic in Model Colony, Karachi.
Plain HTML/CSS/JS — no build step, no framework, no dependencies to install.

## Files

| File | What it is |
|------|-----------|
| `index.html`, `*.html`, `blog/*.html` | Hand-maintained static pages (no build step). Blog/area pages can be generated by `content-pipeline/gen_article.py` and published by `content-pipeline/publish-next.js`. |
| `styles.css` / `script.js` | Styling and behaviour. `script.js` holds the WhatsApp/phone constants, the booking form (WhatsApp first, optional email copy through `RELAY_URL`), GA4 click events (`whatsapp_click`, `phone_click`, `generate_lead`). |
| `CNAME` | GitHub Pages custom domain: `karachihijama.com`. |
| `robots.txt` / `sitemap.xml` | Crawl rules (search + AI crawlers allowed) and every indexable URL with lastmod. Add new pages to the sitemap. |
| `llms.txt` / `llms-full.txt` | Plain-text summaries for AI answer engines (facts, prices, links, FAQ answers). Update when prices or pages change. |
| `404.html` / `privacy.html` | Not-found page (noindex) and privacy policy (GA4, WhatsApp, optional Gmail relay). |
| `indexnow_ping.py` + `f381dff8a72f4bc563bb943551e6faa6.txt` | IndexNow key file and a stdlib script that submits all sitemap URLs after a deploy: `py -3.12 indexnow_ping.py` (`--dry-run` to preview). |

## Contact number and enquiry relay

WhatsApp / phone: edit `CLINIC_WHATSAPP` and `CLINIC_PHONE_DISPLAY` at the top of `script.js` (every button reads them), and the `telephone` values in the JSON-LD blocks.

Email copies of bookings: set `RELAY_URL` in `script.js` to the owner's Google Apps Script relay URL (site id `karachihijama.com`). Empty = WhatsApp only. The privacy note under the form appears automatically when it is set.

## Reviews

Only real reviews may be shown. The homepage links to the Google Business Profile instead of showing testimonials; do not add AggregateRating/Review markup unless genuine reviews with a verifiable source are shown on the page.

## Preview locally

No build needed. From this folder:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

Or just open `index.html` directly in a browser (the Google Map iframe and the on-demand Urdu font need internet).

## Deploy (handled by the orchestrator)

Served by GitHub Pages from this repo with the custom domain in `CNAME`. `.nojekyll` is in place. After a deploy, run `indexnow_ping.py`.

### Medical-honesty note (do not remove)
The site frames Hijama and Unani strictly as **traditional / complementary care** and carries a visible medical disclaimer in the services section and footer. Do not add cure claims, guaranteed outcomes, or disease-specific promises — this protects the clinic legally.
